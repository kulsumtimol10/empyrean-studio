# The Empyrean Studio — Interactive Fourth Wing Experience

An interactive creative-engineering web application inspired by Rebecca Yarros's *Fourth Wing* (The Empyrean Series). Built with zero external runtime dependencies using HTML5 Canvas, 3D CSS perspective transforms, procedural fractal lightning algorithms, composite 2D torchlight shaders, and the Web Audio API.

## ✨ Three Core Interactive Experiences

1. **BookTok 9:16 Holographic Foil Dossier & Quartermaster Receipt Studio**
   - Real-time 3D perspective tilt tracking (`rotateX` / `rotateY`) with dynamic color-dodge specular foil glare.
   - Custom client-side 720×1280 PNG renderer (`HTMLCanvasElement.toDataURL`) engineered for instant sharing on TikTok Stories, Instagram Reels, and BookTok.
2. **The Mental Bond: Procedural Shadow × Lightning Physics Visualizer**
   - Recursive midpoint-displacement fractal lightning algorithm paired with spring-damped shadow ribbon particle physics.
   - Interactive signet modes (*Violet × Xaden Dual Bond*, *Tairn's Obsidian Thunder*, and *Andarna's Feathertail Time-Stop* temporal scaling) with synthesized Web Audio API thunder and harmonic chimes.
3. **Classified Sub-Vault: Interactive Torchlight X-Ray Shader**
   - Dual-layer HTML5 Canvas composite clipping mask that simulates holding a flickering dragonfire torch over censored Navarre Scribe Quadrant decrees to reveal hidden Tyrish rebellion ink underneath.

## 🚀 Deploy to GitHub Pages in 60 Seconds

1. Create a new public repository on GitHub (e.g., `empyrean-studio`).
2. Upload `index.html` and `README.md` to the root of your repository (or run `git init && git add . && git commit -m "Initial commit" && git push`).
3. In your GitHub repository, navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` (and `/ (root)`), and click **Save**.
5. Your project will be live at `https://<your-github-username>.github.io/empyrean-studio/`.
